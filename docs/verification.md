主输入为 8 个特征 × 4 个结局；替代输入为 10 × 5，增加长标签与新结局、改变行列顺序和数值。已查看主图、并排对照、PDF 栅格化结果及替代 PNG，核对热图和 Function 区间面板的数据来源、共同行序、符号配色和零中心色标。

PDF 检查曾发现色条在矢量阅读器中的细白缝；已按照 Matplotlib 官方说明给不透明色条设置同色边线，重新渲染并实际查看，白缝消失。首次参考 PNG 和首次源码继续保留，差异写入条目审核。[技术依据](../SOURCES.md)

## 结论的适用范围

两个参考图都是明确记录来源的自生成合成基准，适合验证工程闭环和新数据复用。本次没有用户真实收藏图，也没有用陌生论文截图独立测量重建准确率。数据中的点估计和区间端点都是示意数值，没有拟合统计模型或宣称置信覆盖率。

本次已实际测试 Python 示例；R 条目执行入口虽已实现，但没有运行 R 示例。未在原生 Windows/macOS 上执行，设置 Git 换行选项的检查只覆盖文件字节保留问题。固定直接依赖和字体有助于重现，但不承诺不同系统、字体安装及底层渲染库之间位级一致。

GitHub Actions workflow 已提供，并在本地执行了对应检查流程；尚未向真实远程仓库推送，因此没有远程 Actions 运行结果。网页属于下一阶段，本版提供目录与公开预览导出接口。

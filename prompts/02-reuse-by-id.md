图库位置：[仓库路径、可访问的 GitHub 仓库，或已导出的单条目目录]
本次数据：[文件或数据说明]
想保留的设计：[配色、布局、图例、标注等；未指定时保留核心设计]

先运行或读取这个条目的 `context`/`AGENT_BRIEF.md`，再看预览、`style.yaml`、数据契约及确实需要的代码。直接处理这个 ID，不搜索整个图库。

请先把当前数据的列、单位、估计量、区间含义和类别映射到该条目的输入要求。按新研究的科学含义调整轴尺度、基准线和标签：例如 OR/HR 的无效应参考值（null value）是 1，回归系数通常以 0 表示无效应；不要因为原图用对数轴就机械沿用。原条目中的示例数据、显著性标记和文字结论不能带入新研究。

尽量保留我指定的颜色与布局；遇到更多类别、更长标签或不同范围时，在维持可读性的基础上调整。先用现成配置解决，只在确有需要时修改代码。

将新代码、数据映射、样式、运行记录和成图保存到本次研究项目。使用 CLI 时给独立 `--out`，不要覆盖图库内的原图和经典复现。若需要带出条目，用 `bundle ID --out ...`；无需复制整个图库。

实际运行并查看结果，核对数字、标签、单位、区间及截断情况。最后告诉我用了哪个 ID、保留了哪些设计、为当前数据做了哪些必要改变，以及图和代码的位置。

这次的适配不自动变成全局偏好，也不自动修改收藏条目。若我要求将改进版入库，再更新原条目或建立明确的新 ID。
